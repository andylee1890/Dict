# 词典资源仓库

本仓库保存可公开分享的词典资源、样式文件、封面和发布索引。

资源均来自网络，仅供学习和交流；如有权利方要求，请联系处理。

[更多资源下载](https://downloads.freemdict.com/)

## 发布规则

- `.mdx`、`.mdd`、`.db` 仅作为本地发布源，不进入 Git 历史。
- 每个顶层文件夹对应一个 release。
- release 里包含该文件夹下除 `.db`、`.bak` 外的公开文件。
- `Example.png` 作为主封面。
